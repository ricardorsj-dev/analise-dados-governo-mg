# 📊 Análise Comparativa: Governo Pimentel x Governo Zema em Minas Gerais

## 📌 Sobre o Projeto

Este projeto realiza uma análise comparativa de indicadores econômicos, fiscais e sociais entre os governos de Fernando Pimentel e Romeu Zema em Minas Gerais utilizando Python e bibliotecas de análise de dados.

O objetivo é transformar dados públicos em visualizações claras e objetivas, permitindo uma análise baseada em evidências — não em narrativas políticas.

---

* Pandas
* Matplotlib
* Seaborn

# 📊 Principais Insights

## 💰 PIB Estadual

Os dados mostram crescimento consistente do PIB durante os anos analisados do governo Zema.

---

## 👨‍🏫 Pagamento dos Servidores

A análise evidencia:

* redução do parcelamento salarial
* pagamentos mais previsíveis
* menor atraso no recebimento dos salários

---

## 🛡️ Segurança Pública

Os indicadores mostram queda progressiva na taxa de homicídios ao longo dos anos analisados.

---

## 🏥 Saúde Pública

Os dados indicam aumento percentual da aplicação de recursos em saúde.
